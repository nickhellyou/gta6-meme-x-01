with the make.fun ghost as its emblem. The navy band at the bottom is
the document's own resolution: "Signing bonus $250 paid by my AI agent

Play code: `makefun-dream-buoy-ledge`. Status: fifth revision rendered
and verified (Rockstar HR application letter); the X post has NOT been
made yet — `POST.json` still holds the SIM post address.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes `out/meme.png` (the meme, 1200x1200) and copies
`POST.json` to `out/POST.json`. Two runs produce byte-identical output.
